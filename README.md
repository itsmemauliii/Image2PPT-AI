# Image2PPT AI

Convert images into editable PowerPoint presentations.

## Features

- Upload Image
- OCR
- Editable Text
- PowerPoint Export
- Streamlit Interface

## Installation

```bash
git clone https://github.com/yourusername/image2ppt-ai

cd image2ppt-ai

pip install -r requirements.txt

streamlit run app.py
```

## Tech Stack

- Streamlit
- PaddleOCR
- OpenCV
- Python-PPTX
